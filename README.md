# تسعير الليلة في شقق نيويورك (NYC Airbnb)

## المشكلة وهدف المشروع
يواجه مالك الشقة أو الغرفة الجديدة في نيويورك صعوبة في تحديد سعر الليلة المناسب في سوق يضم قرابة 49 ألف إعلان بأسعار متباينة؛ إذ يؤدي المبالغة في السعر إلى ضعف الإقبال، بينما يؤدي التسعير المنخفض إلى خسارة عائد محتمل. يهدف هذا المشروع إلى تحليل العوامل المؤثرة في السعر وتقديم أداة مساعدة لتقدير سعر منطقي وتنافسي.

## البيانات ورابط التطبيق
- *البيانات:* data/clean.csv (48,884 إعلاناً عبر أحياء نيويورك الخمسة).
- *رابط التطبيق المباشر:* https://nyc-airbnb-pricing-dhopmickyp8vywbcfpyt2e.streamlit.app

## أهم الاكتشافات والتوصيات بالأرقام
- *المتوسط مقابل الوسيط:* متوسط السعر *$152.76* مقابل وسيط عام *$106.00*، مما يوضح أثر القيم المرتفعة جداً ويجعل الوسيط مقياساً أدق للسعر المعتاد.
- *الأثر حسب الحي الرئيسي:* تتصدر *Manhattan* بأعلى وسيط سعر بقيمة *$150.00* لليلة.
- *الأثر حسب نوع الغرفة:* تتصدر فئة *Entire home/apt* بوسيط سعر يبلغ *$160.00* مقارنة بباقي الفئات.
- *التوصيات:* تسعير الوحدات الكاملة في الأحياء عالية الطلب بالاستناد إلى وسيط الحي ونوع الغرفة، واعتماد سعر تنافسي قريب من وسيط الفئة في الأحياء الأقل سعراً، مع اعتبار البيانات مرجعاً أولياً ومراعاة عوامل غير مرصودة مثل جودة الصور والتقييمات (الارتباط لا يعني السببية).
