# تسعير الليلة في شقق نيويورك القصيرة

## المشكلة
منصة تأجير شقق قصيرة في نيويورك تضم قرابة 49 ألف إعلان بأسعار ليلة من 10 إلى 10,000 دولار، والمالك الجديد يسعّر بالتخمين؛ فإذا رفع السعر لا يحجز أحد وإذا خفضه يخسر.

## سؤال العميل
- وش اللي يرفع سعر الليلة أو ينزّله؟
- كم السعر المناسب لشقة جديدة؟
